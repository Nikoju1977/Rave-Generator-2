STUDIO NIKO / RAVE GENERATOR 2 — Made for warehouse, acid & free-party production.TR-909 / TR-303 sont des inspirations sonores ; ce logiciel est indépendant de Roland.

Mode d’emploi — Rave Generator 2

Premiers sons : cliquez sur PLAY pour autoriser Web Audio, puis modifiez les pads oranges. Un clic active/désactive un coup ; clic droit (ou appui prolongé) change son accent.

Patterns : A à H, longueur 16 ou 32 pas. Les pages 01–16 / 17–32 affichent les mesures. COPY et PASTE dupliquent un pattern. GENERATE crée une batterie aléatoire ; VARIATION modifie le groove courant.

Acid : touchez un pas vert, réglez sa note, l'accent et le glissé. La plage va de C1 à C5. Réglez le filtre, la résonance, l'enveloppe et la forme d’onde dans MIXER + FX.

Mixage : 12 canaux dont la basse, volume et M/S (Mute/Solo), réglages de pitch/decay/pan dans SOUND DESIGN. Vous pouvez importer des samples WAV, MP3 ou OGG sur les canaux percussifs.

Arrangement : configurez les 8 slots et leurs répétitions, puis activez PLAY SONG MODE. Au prochain PLAY, la séquence suit les slots. Les exports suivent aussi ce mode.

Enregistrement : REC WAV enregistre la sortie master en temps réel dans un fichier WAV PCM stéréo 16 bits (fréquence native de votre appareil, sans microphone). Le bouton STOP WAV télécharge le fichier. EXPORT WAV réalise un rendu hors ligne PCM stéréo 44,1 kHz / 16 bits sans attendre la durée de la séquence. Sur mobile, les fichiers se trouvent généralement dans Téléchargements. Pour Suno, enregistrez ou exportez le WAV, puis utilisez PARTAGER WAV (si votre téléphone propose le partage de fichiers vers Suno) ou ouvrez SUNO et importez le fichier via Upload Audio. Le bouton SUNO ouvre uniquement le site officiel : aucun envoi automatique ni connexion à votre compte Suno n’est effectué. MIDI exporte des notes distinctes sur 12 pistes.

Sauvegarde : les réglages se mémorisent localement si votre navigateur l’autorise. PROJECT JSON permet de transporter vos patterns et samples importés vers un autre appareil. Les navigateurs imposent un premier geste utilisateur avant toute lecture sonore.

Conseil : pour installer la PWA, hébergez le dossier sur un serveur HTTPS. Le fichier HTML est aussi utilisable localement dans un navigateur.
